## 2. 修复内容

### 文档、预览与导出

1. PDF 使用完整 Markdown 渲染模式，保留页眉、页脚，修复仅含这些内容时误报无正文的问题。
2. 通用 RapidOCR 补漏写入结构化结果，再生成 Markdown 与 JSON；保留逐页审计、置信度、坐标和异常信息。
3. 选页结果携带原始 `page_idx`；PDF 热区按页面宽高分别缩放，修复错页和错位。
4. 修复 PDF 重载按钮缺少事件函数、详情删除按钮缺少 API/store 实现、非 PDF 详情空白半屏。
5. Markdown HTML 使用 DOMPurify 清理，保留表格和公式，移除脚本、事件属性和危险链接。
6. 修复上传清空、删除后重选同一文件、重复文件和批量提交状态处理。
7. 无效的旧版 MinerU 调试导出开关已从前端移除或说明；新版始终启用的公式/表格选项固定显示。

### 引擎、任务与后端

1. 通用预设按扩展名分派文本、Office、EPUB、生物格式和媒体；补齐 BMP/TIFF/WebP/WebM 路由。
2. Windows 旧 DOC/PPT 在缺少 LibreOffice 时可调用本机 Office 的独立 COM 转换进程；禁用宏并设置超时。
3. 修复父子任务结果路径、ZIP 合并 JSON 和标准输出选择顺序，避免视频关键帧辅助 JSON 覆盖主 JSON。
4. 活跃/已完成任务不允许直接重试，拒绝操作前保留已有输出；活跃任务不允许清缓存。
5. 拒绝负页码、反向页码和无效解析方法；清理天数、超时参数必须大于零。
6. 修复暂停状态样式、暂停任务轮询、取消后重试、批量取消与状态冲突提示；时间显示正确转换 UTC。

### 音视频与水印

1. SenseVoice 语言别名映射到模型代码；普通转写分离内部标签与正文，保留原始文本，读取真实时长，并启用模型时间戳。
2. 使用模型 `words` 与 `timestamp` 配对，避免按空格切分造成中文丢失；缺少可靠配对时保留整段文字。
3. 无音轨视频走关键帧 OCR；修复白色幻灯片、短视频首帧过滤及缺少 ImageHash 依赖。
4. 提取音频放入任务目录，视频主 JSON 保留音频与关键帧信息。
5. 原生文字水印关键词真正删除对应文字，同时保留正文和用户批注；支持 CPU，预处理失败有可见提示。

### 系统、认证与开发入口

1. 关闭 RustFS 的本机模式支持 Logo 上传和预览，保存设置后应用；校验图像格式和资源文件名。
2. 修复 MCP SSE/消息入口的 ASGI 返回问题。
3. 修复 Vite `/api` 代理误匹配 `/api-docs`、Scalar 内容配置与 Bearer 鉴权配置。
4. 系统名称保存后即时更新页面；移除可能丢失其他表单输入的强制重载。
5. 登录使用安全的站内返回路径；退出先等待令牌处理完成，再跳转登录页。
6. 修复旧桌面快捷方式仍指向 Windows PowerShell 的问题，重复启动可打开已运行页面。
7. 新增 Vue 模板类型检查、后端开发测试依赖和回归测试；运行时输入及验收资料目录加入 Git 忽略规则。

## 5. 仍有明确限制的能力

- **自动图片水印去除仍为实验功能。** 检测模型已安装并实际执行，但未识别合成样本中的灰色 SAMPLE 水印。原生文字关键词去除已通过；不能把自动检测记为去除成功。当前修复器为 OpenCV，未安装存在依赖冲突的 LaMa。
- **外部图片描述模型、远程 VLM、SSO、生产 Redis/RustFS、Dify/外部 AI 客户端**缺少本机实际配置，未完成这些服务的真实正向联调。Webhook 的签名、重试和地址限制有自动化测试，未向用户真实第三方回调地址发送请求。
- 当前 SAML 回调源码明确返回未实现；本次原生部署未启用 SAML。OIDC 需要实际身份提供方配置才能验收。
- OCR 与表格识别不能保证任意模糊、手写、复杂版式 PDF 完全准确。RapidOCR 已通用集成，逐页审计可定位补漏与异常；补录文字不代表恢复了完整表格结构。
- 真实媒体测试采用合成短音频和视频，未覆盖所有编码、超长媒体或复杂多人对话。
